# 💰 AI Personal Finance Tracker

An interactive AI-powered Personal Finance Tracker built using **Python, Streamlit, SQLite, Pandas, and Plotly** to help users manage expenses, analyze spending patterns, monitor budgets, and gain intelligent financial insights through dynamic dashboards and visual analytics.

---

# Features

## $ Expense Management
- Add new expenses
- Delete expenses
- Store transactions using SQLite database
- Persistent local data storage

## Dashboard Analytics
- Total expenses overview
- Highest expense tracking
- Transaction count monitoring
- Budget status monitoring

## Visual Insights
- Expense category analysis
- Interactive pie chart visualization
- Monthly expense trend analysis
- Dynamic and responsive charts using Plotly

## AI Financial Insights
- Highest spending category detection
- Average transaction analysis
- Smart budget alerts
- Personalized financial recommendations

## Export Functionality
- Download expense reports as CSV files

#  Installation & Setup

## 1️) Clone Repository

```bash
git clone https://github.com/your-username/AI-personal-finance-tracker.git
```

## 2️) Navigate to Project Folder

```bash
cd AI-personal-finance-tracker
```

## 3️) Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️) Run Streamlit App

```bash
streamlit run app.py
```
