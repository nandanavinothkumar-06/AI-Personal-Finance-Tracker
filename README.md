# AI Personal Finance Tracker

AI Personal Finance Tracker is an interactive finance management application built using Python, Streamlit, SQLite, Pandas, and Plotly to help users track expenses, monitor budgets, analyze spending behavior, and gain financial insights through visual dashboards and analytics.

The project focuses on practical implementation of:
- Data analytics
- Dashboard development
- Database integration
- Financial data visualization
- CRUD operations
- Business logic implementation
- Interactive web application development

---

# Problem Statement

Managing personal finances manually can become difficult when expenses increase over time. Many users struggle with:
- Tracking daily expenses
- Understanding spending habits
- Monitoring monthly budgets
- Visualizing financial trends
- Organizing financial records efficiently

This project aims to provide a centralized finance tracking platform that simplifies expense management and delivers meaningful financial insights through interactive analytics.

# Working Flow

1. User enters expense details
2. Expense data is stored in SQLite database
3. Dashboard fetches financial records dynamically
4. Analytics module processes expense data
5. Charts and insights are generated interactively
6. Budget monitoring system analyzes spending behavior

# Installation Guide

## 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-personal-finance-tracker.git
```

---

## 2. Navigate to Project Folder

```bash
cd AI-personal-finance-tracker
```

---

## 3. Create Virtual Environment

```bash
python -m venv venv
```

---

## 4. Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

---

## 5. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 6. Run Streamlit Application

```bash
streamlit run app.py
```
